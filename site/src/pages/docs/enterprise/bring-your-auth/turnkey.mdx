# Turnkey

Use a custom adapter when Turnkey owns signer infrastructure and the app wants to expose Tempo account operations through the Accounts SDK.

## Integration shape

The app provides the Turnkey client shape to the adapter. The adapter translates Accounts SDK requests into Turnkey signing requests and maps Turnkey responses back into provider responses.

Target workspace for a future runnable example: `examples/enterprise-turnkey/`.

## Integration Checklist

- Accept an app-provided Turnkey client shape.
- Keep Turnkey-specific dependencies out of the root SDK path.
- Define which app surface proves user intent before signing.
- Map Turnkey signing responses into Accounts SDK responses.
- Test connect, payment, and spend-permission flows.

## Review gates

- Non-Turnkey consumers do not inherit a hard Turnkey dependency.
- Turnkey errors map to provider errors that app UI can display.
- Account creation, approval, denial, and recovery states have an owner.
- Connect, payment, and spend-permission guide flows pass through the adapter.
