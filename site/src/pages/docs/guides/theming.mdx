# Theming

## Outcome

Configure the appearance of embedded account surfaces without changing the signing adapter contract.

## Demo

:::info[Phase 2 demo]
This section will become an interactive demo in Phase 2.
:::

| Item | Value |
| --- | --- |
| Final interaction | Switch theme settings and compare Tempo Wallet iframe, popup, and app-owned WebAuthn UI. |
| Target workspace | `examples/theming/`. |
| Success state | The page shows which surfaces changed and which surfaces remain owned by hosted wallet infrastructure. |
| Implementation owner surface | Tempo Wallet exposes supported hosted UI theme hooks. WebAuthn and custom adapters are fully bring-your-own UI. |

## Prerequisites

- An adapter choice.
- The account surfaces the app needs to theme.
- Browser coverage for iframe and popup modes when using Tempo Wallet.

## Setup

Install the SDK package.

```bash
pnpm add accounts
```

Choose the adapter whose surfaces need theming.

For Tempo Wallet, configure supported dialog theme options only. For WebAuthn and custom adapters, theme your own account, approval, recovery, and error surfaces as part of the app.

## Implementation

Open the embedded surface in the target browser contexts.
Apply the supported theme options.

## Verification

Compare the embedded dialog, popup, and mobile behavior.

## Production notes

- Hosted wallet surfaces may intentionally limit theming to preserve trust and security cues.
- Domain-bound and custom adapters may own more of the UI surface directly.
- Do not hide or visually weaken approval, account, origin, or recovery cues.
- Test iframe and popup modes separately because browser security constraints differ.
