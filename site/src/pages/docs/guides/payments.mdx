# Payments [An app sends a stablecoin payment from the user's Tempo Account.]

## Overview

A payment is a stablecoin transfer from the user's Tempo Account. The session's [access key](/docs/guides/access-keys) signs it with no prompt, within a limit that the user approves once. If no access key can pay, the account owner signs it on Tempo ID's payment page.

An app sends a payment of its own, such as for an order, in one call. An [MPP](https://mpp.dev) endpoint charges with an HTTP 402 response, which the access key pays.
