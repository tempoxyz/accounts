# Fee sponsorship [A fee payer pays the fees of the transactions of users.]

## Overview

Tempo has no native gas token, so the sender of a transaction pays its fee in a stablecoin. A Tempo transaction can also name a fee payer: a second account that co-signs the transaction and pays its fee.

An app sponsors fees so that a user with no stablecoin can still send a transaction. Each guide uses a different fee payer.
