# Access keys [An access key signs for the user's Tempo Account within limits that the user approves.]

## Overview

An access key signs transactions for the user's Tempo Account with no wallet prompt. The account owner approves it once on Tempo ID's approval page, with a spending limit and an expiry. The chain refuses each transfer above the limit.

An app needs an access key to send [payments](/docs/guides/payments), pay [subscriptions](/docs/guides/subscriptions), or send transactions with [Viem](/docs/guides/viem). An app that only signs users in needs none.
