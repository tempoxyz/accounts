# Subscriptions [A user approves a recurring charge once, and the payee charges each period.]

## Overview

A subscription charges the user's Tempo Account once each period, such as 1 OUSD each month. The user approves an [access key](/docs/guides/access-keys) whose spending limit resets each period, and the chain refuses a charge above that limit.

If the app charges, its backend holds the access key. If another merchant charges, such as an API, the user approves the merchant's own access key through [MPP](https://mpp.dev), a protocol of HTTP 402 payments.
