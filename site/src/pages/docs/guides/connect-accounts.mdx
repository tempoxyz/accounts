# Connect Accounts

## Outcome

Connect a user account, read its address, and keep the app code on one provider surface while the adapter handles signing and account UI.

## Demo

:::info[Phase 2 demo]
This section will become an interactive demo in Phase 2.
:::

| Item | Value |
| --- | --- |
| Final interaction | Connect an account with Tempo Wallet, then repeat the same app flow with WebAuthn. |
| Target workspace | `examples/connect-accounts/`, seeded from `examples/basic/`. |
| Success state | The app shows the connected address, connection status, and selected adapter. |
| Implementation owner surface | Tempo Wallet uses hosted account and approval UI. WebAuthn uses app-owned UI. |

## Prerequisites

- A React app configured with Wagmi.
- The Tempo chain in your Wagmi config.
- An adapter choice. Most apps should start with Tempo Wallet.

## Setup

Install `accounts` together with Wagmi and Viem.

```bash
pnpm add accounts wagmi viem
```

Choose an adapter. Most apps should start with Tempo Wallet because it includes hosted account and approval UI. Use WebAuthn when the app owns passkey registration, authentication, recovery, and UI.

```tsx
import { createConfig, http } from 'wagmi'
import { tempo } from 'wagmi/chains'
import { tempoWallet } from 'wagmi/connectors'

export const config = createConfig({
  chains: [tempo],
  connectors: [tempoWallet()],
  transports: {
    [tempo.id]: http(),
  },
})
```

For a domain-bound passkey flow, switch the connector to `webAuthn({ authUrl: '/auth' })` and provide the matching server handler from [Authentication](/docs/guides/authentication).

## Implementation

Render the configured connector and call `connect`.

```tsx
import { useConnect, useConnectors } from 'wagmi'

function Connect() {
  const { connect } = useConnect()
  const connectors = useConnectors()

  return connectors.map((connector) => (
    <button key={connector.uid} onClick={() => connect({ connector })}>
      Connect
    </button>
  ))
}
```

## Verification

Read the connected address from Wagmi connection state.

```tsx
import { useConnection } from 'wagmi'

function Account() {
  const { address, status } = useConnection()
  return <pre>{JSON.stringify({ address, status }, null, 2)}</pre>
}
```

## Production notes

- Use HTTPS for embedded Tempo Wallet iframe flows and all browser passkey flows.
- Keep adapter selection explicit in app code so UI ownership is clear to future maintainers.
- Treat WebAuthn and custom adapters as bring-your-own UI. The app must handle account creation, approvals, recovery, errors, and empty states.
