# Connections [An API pays for a user with an access key that it holds for one connection.]

## Overview

A connection is an OAuth grant of one user, through one app, to one API, such as a paid MCP server. The API, not the app, holds the [access key](/docs/guides/access-keys), and pays from the user's Tempo Account within the limits that the user approved.

An API uses connections if it charges the user for its own work, and the app only calls it. If the app itself pays, the app's own access key signs, as [Payments](/docs/guides/payments) shows.
