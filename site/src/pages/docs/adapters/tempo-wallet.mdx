# Tempo Wallet Adapter

Tempo Wallet is the hosted adapter for apps that want embedded account creation and signing without owning auth, passkeys, or wallet infrastructure.

Use it when you want:

- A universal account that can move across apps.
- Hosted approval surfaces through iframe or popup dialogs.
- Tempo-managed passkey and signing infrastructure.
- A fast path for app teams that do not need to build a wallet.

## Usage

:::code-group

```tsx twoslash [Web (Wagmi)]
import { createConfig, http } from 'wagmi'
import { tempo } from 'wagmi/chains'
import { tempoWallet } from 'wagmi/connectors'

export const config = createConfig({
  chains: [tempo],
  connectors: [tempoWallet()],
  transports: {
    [tempo.id]: http(),
  },
})
```

```ts twoslash [Web (Vanilla)]
import { Provider, tempoWallet } from 'accounts'

const provider = Provider.create({
  adapter: tempoWallet(),
})
```

```ts twoslash [React Native]
import { Provider } from 'accounts'
import { tempoWallet } from 'accounts/mobileWebAuth'
import { openAuthSession } from 'accounts/react-native/expo-web-browser'

const provider = Provider.create({
  adapter: tempoWallet({
    baseUrl: 'https://app.example',
    openAuthSession,
    redirectUri: 'com.example.app:/auth',
  }),
})
```

```ts twoslash [CLI]
import { Provider } from 'accounts/cli'

const provider = Provider.create()
```

:::

## Mobile

On mobile there is no embedded dialog. The adapter connects through [mobile web auth](/docs/api/mobileWebAuth): each request opens Tempo Wallet in a system browser session and completes via an app-link callback to `redirectUri`.

Tempo Wallet identifies your app through the consumer discovery document served at `baseUrl`, and that document must list the exact `redirectUri`. See [Consumer Discovery](/docs/api/mobileWebAuth#consumer-discovery) for the document format, and the [React Native guide](/docs/guides/react-native) for platform setup.
