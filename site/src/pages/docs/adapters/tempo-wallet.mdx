# Tempo Wallet Adapter

Tempo Wallet is the hosted adapter for apps that want embedded account creation, approvals, onramp, and signing without owning auth, passkeys, or wallet UI infrastructure.

Use it when you want:

- A universal account that can move across apps.
- Hosted approval surfaces through iframe or popup dialogs.
- Tempo-managed passkey and signing infrastructure.
- A fast path for app teams that do not need to build a wallet.

## What Tempo Wallet owns

Tempo Wallet owns the hosted account and approval surfaces. Your app still owns the surrounding product flow: when to request connection, what action the user is approving, how success is shown, and how failures are recovered.

| Surface | Owner |
| --- | --- |
| Account creation and sign-in | Tempo Wallet |
| Approval UI | Tempo Wallet |
| Onramp and account management surfaces | Tempo Wallet |
| Product context before and after approval | Your app |
| Error, loading, and retry states around the dialog | Your app |

## Configure

```tsx
import { createConfig, http } from 'wagmi'
import { tempo } from 'wagmi/chains'
import { tempoWallet } from 'wagmi/connectors'

export const config = createConfig({
  chains: [tempo],
  connectors: [tempoWallet()],
  transports: {
    [tempo.id]: http(),
  },
})
```

## Production notes

- Use HTTPS so embedded iframe and passkey flows work consistently.
- Decide iframe versus popup behavior before launch and test both browser-blocking and cancellation states.
- Keep Content Security Policy directives aligned with the hosted wallet origin.
- Keep user-facing copy short before opening the hosted approval surface.
- Show the selected account, requested action, and result inside your app after the hosted flow returns.
