# `WebAuthnCeremony`

Pluggable strategy for WebAuthn registration and authentication ceremonies. A `WebAuthnCeremony` controls how challenges are generated and responses are verified during passkey registration and login.

Use the server-backed ceremony for most apps. Use `.from` only when you already operate a WebAuthn ceremony service and need to adapt it to the SDK.
