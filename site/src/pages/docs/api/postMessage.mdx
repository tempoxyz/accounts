# `postMessage`

Creates an adapter that sends provider RPC requests to a wallet web page over a [uRPC postMessage session](https://github.com/tempoxyz/urpc/blob/main/specs/transport-window.md).

One provider holds one session to one wallet window. The wallet page — a centered popup by default — mounts on the first request and stays bound to the session: sequential requests reuse the open window, navigating it from one approval to the next. Closing the window rejects the in-flight request, and the next request mounts a fresh one. `wallet_disconnect` tears the session down.

The wallet identifies the app by its browser-verified window origin, so no discovery document is required; `name` and `rdns` only describe the provider identity announced to the app.

Both adapters are exported from the root entry — `postMessage` and `tempoWalletPostMessage` — and from the `accounts/postMessage` subpath as `postMessage` and `tempoWallet`.

## Usage

```ts twoslash
import { Provider } from 'accounts'
import { postMessage } from 'accounts/postMessage'

const provider = Provider.create({
  adapter: postMessage({
    host: 'https://wallet.example/post-message',
    name: 'Example Wallet',
    rdns: 'com.example.wallet',
  }),
})
```

## tempoWallet

`tempoWallet()` is a template over `postMessage()` preconfigured with the Tempo Wallet post-message page and provider identity.

```ts twoslash
import { Provider } from 'accounts'
import { tempoWallet } from 'accounts/postMessage'

const provider = Provider.create({
  adapter: tempoWallet(),
})
```

## Mounting in an iframe

The adapter owns the wire; the app owns the mount. Pass `target` to mount the wallet page somewhere other than a popup — for example an iframe the app shows while requests are pending. Passkey ceremonies inside a cross-origin iframe require the `publickey-credentials-*` permissions in the frame's `allow` attribute.

```ts twoslash
import { postMessage } from 'accounts/postMessage'

let frame: HTMLIFrameElement | undefined

const adapter = postMessage({
  host: 'https://wallet.example/post-message',
  name: 'Example Wallet',
  rdns: 'com.example.wallet',
  target: ({ host }) => {
    frame = document.createElement('iframe')
    frame.allow = 'publickey-credentials-create *; publickey-credentials-get *'
    frame.src = host!
    document.body.appendChild(frame)
    return frame.contentWindow
  },
  close: () => frame?.remove(),
})
```

## Parameters

### close

- **Type:** `(handle: Window | MessagePort) => void | Promise<void>`
- **Optional**

Cleanup for the mounted handle, called when the session closes. Defaults to `handle.close()`, which closes a popup the adapter opened.

### host

- **Type:** `string`
- **Required by:** `postMessage`

URL of the wallet's post-message page. The adapter tags the URL with your app's origin so the wallet can pin its responses before the first frame arrives.

### name

- **Type:** `string`
- **Required by:** `postMessage`

Provider display name.

### rdns

- **Type:** `string`
- **Required by:** `postMessage`

Reverse-DNS provider identifier.

### target

- **Type:** `({ host }) => Window | MessagePort | null | Promise<Window | MessagePort | null>`
- **Optional**

Override how the wallet page is mounted. Called when the session (re-)opens; receives the page URL and returns a `Window` or `MessagePort` handle. A nullish handle (e.g. a blocked `window.open`) rejects the request with `PostMessage.PopupBlockedError`. Defaults to opening a centered popup window.
