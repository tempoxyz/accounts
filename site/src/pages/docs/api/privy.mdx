# `privy`

Creates a Privy adapter for React apps using `@privy-io/react-auth`.

Import it from `accounts/react/privy`. The adapter opens Privy's login UI through a React boundary, reads Privy's hook state, and returns embedded Ethereum wallets to the Accounts SDK. When Privy exposes a public key, the adapter builds a full Tempo viem account with `viem/tempo` `Account.from(...)`; otherwise it uses Privy's embedded provider signer fallback.

## Usage

```ts
import { Provider } from 'accounts'
import { privy } from 'accounts/react/privy'

export const provider = Provider.create({
  adapter: privy(),
})
```

The helper expects `PrivyAccountsBridge` under `PrivyProvider`:

```tsx
import { PrivyProvider } from '@privy-io/react-auth'
import { PrivyAccountsBridge } from 'accounts/react/privy'

root.render(
  <PrivyProvider appId={appId}>
    <PrivyAccountsBridge />
    <App />
  </PrivyProvider>,
)
```

The bridge resolves connect requests with Privy's embedded Ethereum wallets, Privy's viem account signer when available, and matching public keys when Privy exposes them.

## Parameters

### icon

- **Type:** `` `data:image/${string}` ``
- **Optional**

Data URI of the provider icon.

```ts
import { Provider } from 'accounts'
import { privy } from 'accounts/react/privy'

const provider = Provider.create({
  adapter: privy({
    icon: 'data:image/svg+xml,...', // [!code focus]
  }),
})
```

### name

- **Type:** `string`
- **Default:** `'Privy'`

Display name of the provider.

```ts
import { Provider } from 'accounts'
import { privy } from 'accounts/react/privy'

const provider = Provider.create({
  adapter: privy({
    name: 'My Wallet', // [!code focus]
  }),
})
```

### rdns

- **Type:** `string`
- **Default:** `'io.privy'`

Reverse DNS identifier.

```ts
import { Provider } from 'accounts'
import { privy } from 'accounts/react/privy'

const provider = Provider.create({
  adapter: privy({
    rdns: 'com.example.wallet', // [!code focus]
  }),
})
```

## PrivyAccountsBridge

`PrivyAccountsBridge` is a null-rendering React component. Mount it under `PrivyProvider` and inside the same React tree as the app that creates or uses the Accounts SDK provider.

It exists because Privy's `usePrivy`, `useWallets`, and `useLogin` hooks can only run inside `PrivyProvider`, while the Accounts SDK provider is plain TypeScript.

## Account Behavior

The public React adapter connects all embedded Ethereum wallets returned by Privy. During connect, the bridge materializes each Privy wallet into the shape expected by the internal adapter.

For Privy-hosted embedded wallets, the bridge calls Privy's `toViemAccount({ wallet })` helper and pairs the resulting raw signer with the wallet public key from Privy's authenticated user state when available.

When a public key is present, the adapter validates that it matches the wallet address and builds a full Tempo viem account. When only an address is available, the adapter still signs through Privy's embedded provider fallback.
