# `webAuthn`

Enables domain-bound passkey experiences by wrapping the `local` adapter with WebAuthn registration and authentication flows.

The WebAuthn adapter is bring-your-own UI. The SDK runs the passkey ceremony and signs through the resulting domain-bound account, but your app owns registration screens, login screens, account recovery, approval copy, and error states.

## Usage

```ts
import { webAuthn, Provider } from 'accounts'

const provider = Provider.create({
  adapter: webAuthn({ authUrl: '/auth' }),
})
```

## Parameters

### authUrl

- **Type:** `string`
- **Optional**

URL of a [WebAuthn server handler](/docs/server/handler.webAuthn) (shorthand for `WebAuthnCeremony.server({ url }){:js}`)

:::warning
Cannot be used with `ceremony`.
:::

```ts twoslash
import { webAuthn, Provider } from 'accounts'

const provider = Provider.create({
  adapter: webAuthn({
    authUrl: '/auth', // [!code focus]
  }),
})
```

### ceremony

- **Type:** `WebAuthnCeremony`
- **Default:** `WebAuthnCeremony.server({ url: authUrl }){:js}`

Ceremony strategy for WebAuthn registration and authentication. [See more](/docs/api/webauthnceremony).

:::warning
Cannot be used with `authUrl`.
:::

```ts twoslash
import { webAuthn, WebAuthnCeremony, Provider } from 'accounts'

const provider = Provider.create({
  adapter: webAuthn({
    ceremony: WebAuthnCeremony.server({ url: '/auth' }), // [!code focus]
  }),
})
```

### icon

- **Type:** `` `data:image/${string}` ``
- **Optional**

Data URI of the provider icon.

```ts twoslash
import { webAuthn, Provider } from 'accounts'

const provider = Provider.create({
  adapter: webAuthn({
    authUrl: '/auth',
    icon: 'data:image/svg+xml,...', // [!code focus]
  }),
})
```

### name

- **Type:** `string`
- **Default:** `'Injected Wallet'`

Display name of the provider.

```ts twoslash
import { webAuthn, Provider } from 'accounts'

const provider = Provider.create({
  adapter: webAuthn({
    authUrl: '/auth',
    name: 'My Wallet', // [!code focus]
  }),
})
```

### rdns

- **Type:** `string`
- **Optional**

Reverse DNS identifier.

```ts twoslash
import { webAuthn, Provider } from 'accounts'

const provider = Provider.create({
  adapter: webAuthn({
    authUrl: '/auth',
    rdns: 'com.example.wallet', // [!code focus]
  }),
})
```

## Production notes

- WebAuthn requires HTTPS outside local development.
- The server handler `origin` and `rpId` must match the production domain.
- Use persistent credential storage. `Kv.memory()` is only for development and tests.
- Plan recovery before launch because passkeys are bound to the app origin and authenticator ecosystem.
