# `Dialog.host.useState`

React hook that subscribes to the [`Dialog.host`](/docs/api/dialog.host.create) context's Zustand store. Re-renders whenever the selected slice changes.

## Usage

```ts
import { Dialog } from 'accounts/react'

import { host } from '../lib/config.js'

// Subscribe to the full state.
const state = Dialog.host.useState(host)

// Or subscribe to a slice via a selector.
const ready = Dialog.host.useState(host, (s) => s.ready)
```

## Parameters

### host

- **Type:** `Dialog.Host`
- **Required**

The host context returned from [`Dialog.host.create`](/docs/api/dialog.host.create).

```ts
import { Dialog } from 'accounts/react'

import { host } from '../lib/config.js'

const state = Dialog.host.useState(host) // [!code focus]
```

### selector

- **Type:** `(state: Dialog.State) => selected`
- **Optional**

Function that picks a slice from the store's state. The component only re-renders when the selected value changes (using `Object.is` equality).

```ts
import { Dialog } from 'accounts/react'

import { host } from '../lib/config.js'

const ready = Dialog.host.useState(host, (s) => s.ready) // [!code focus]
const mode = Dialog.host.useState(host, (s) => s.mode) // [!code focus]
```

## Returns

The full `Dialog.State` when no `selector` is provided, otherwise the selector's return value:

```ts
type State = {
  /** Whether the dialog is rendered in an iframe or popup. */
  mode: 'iframe' | 'popup' | undefined
  /** Trusted host origin from MessageEvent. */
  origin: string | undefined
  /** Whether the dialog is ready to display content. */
  ready: boolean
  /** Queued RPC requests received from the host. */
  requests: Dialog.State['requests']
}
```
