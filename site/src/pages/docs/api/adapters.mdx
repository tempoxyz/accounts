# Adapters

Adapters control how accounts are created and managed. Pass an adapter to `Provider.create()` to configure the account management strategy.

## Choose an adapter

| Adapter | Uses | UI owner | Best for |
| --- | --- | --- | --- |
| [`dialog`](/docs/api/dialog) (default) | Tempo Wallet hosted dialog | Tempo Wallet owns account and approval UI | Apps that want the default hosted account path |
| [`webAuthn`](/docs/api/webAuthn) | Domain-bound passkeys | App-owned UI | Apps that own passkey registration, authentication, recovery, and approval states |
| [`local`](/docs/api/local) | Arbitrary account loading and signing | App-owned UI | Custom signing systems, enterprise custody, and adapter experiments |
