# Accounts SDK

Build account experiences on Tempo with common tooling for signing, payments, and approvals. The Accounts SDK gives apps one provider surface and adapter model, so examples, integrations, and agent-generated code can compose across Tempo Wallet, domain-bound WebAuthn, and custom signing infrastructure.

## Choose an adapter

| Adapter | Use it when |
| --- | --- |
| [Tempo Wallet](/docs/adapters/tempo-wallet) | You want a universal wallet without owning auth or signing infrastructure. |
| [WebAuthn](/docs/adapters/webauthn) | You want domain-bound passkey accounts on your own app origin. |
| [Custom adapter](/docs/adapters/custom) | You want to connect Privy, AWS KMS, Turnkey, internal signers, or your own hosted wallet. |

## Demo

:::info[Phase 2 demo]
This section will become an interactive demo in Phase 2. It will reuse the guide examples for connecting an account, making a payment, and authorizing scoped access.
:::

| Flow | Target workspace | Success state | Implementation owner surface |
| --- | --- | --- | --- |
| Connect account | `examples/connect-accounts/` | The app shows the connected Tempo account address. | Tempo Wallet hosted UI by default; WebAuthn variant uses app-owned UI. |
| Make a payment | `examples/payments/` | The app shows a receipt and refreshed balance. | Tempo Wallet approval UI by default; WebAuthn/custom variants use app-owned UI. |
| Authorize access | `examples/spend-permissions/` | The app shows the authorized access key, limits, expiry, and revocation state. | Tempo Wallet approval UI by default; WebAuthn/custom variants use app-owned UI. |
